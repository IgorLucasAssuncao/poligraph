Como ler as etapas

Dentro de uma etapa, a ordem não importa: a posição na coluna é só arrumação. Entre etapas, cada comando espera só os próprios pré-requisitos, não a etapa anterior inteira.

    EXCEÇÕES À REGRA

    • patrimonio e redes não rodam juntos: baixam o mesmo arquivo do TSE para o mesmo lugar do cache.
    • Comandos que chamam o mesmo servidor dividem o limite de ritmo dele. O Portal recusa a partir de uma requisição por segundo.
